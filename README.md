## ✨ About

**EZZ Launcher** is a modern Minecraft Launcher for Windows built with Python.

It is designed to make launching and managing Minecraft Java Edition simple, clean, and fast — with account management, Fabric support, multiple instances, diagnostics, resource management, and more.

## 🚀 Getting Started

1. Download the latest EZZ Launcher release.
2. Install or extract the launcher.
3. Add your Microsoft or offline account.
4. Select your Minecraft version and Fabric setup.
5. Configure your resources, shaders, and world.
6. Launch Minecraft. 🎮
